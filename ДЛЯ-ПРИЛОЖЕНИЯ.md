# Подключение приложения «Мой день» к библиотеке картинок

Сайт-библиотека готов и работает. Нужно научить приложение брать оттуда картинки для карточек.
Ниже всё, что нужно знать о сайте. **Сайт менять не нужно — только приложение.**

---

## 1. Адреса

| Что | Адрес |
|---|---|
| Базовый адрес | `https://dikajabelka.github.io/moyden/` |
| Каталог | `https://dikajabelka.github.io/moyden/catalog.json` |
| Картинка | базовый адрес + поле `file` из каталога |

- Базовый адрес вынести в **одну константу** (`LIBRARY_BASE_URL`). Позже он может смениться
  на собственный домен — тогда поменяем одну строку.
- Хостинг — GitHub Pages: только HTTPS, `Access-Control-Allow-Origin: *`,
  `Cache-Control: max-age=600`, есть `Last-Modified` и `ETag`. Авторизация не нужна.

## 2. Формат `catalog.json`

```json
{
  "version": 1,
  "name": "Картинки «Мой день»",
  "count": 14,
  "updated": "2026-09-24",
  "words": 9,
  "categories": ["игры", "места", "прогулка", "режим", "учёба"],
  "variants": ["девочка", "мальчик", "без людей"],
  "items": [
    {
      "id": "игры_играть_в_мяч-девочка",
      "title": "Играть в мяч",
      "category": "игры",
      "file": "images/игры/играть_в_мяч-девочка.png",
      "bytes": 9981,
      "tags": ["мяч"],
      "word": "играть в мяч",
      "variant": "девочка",
      "style": "рисунок",
      "n": 1,
      "w": 512,
      "h": 512
    }
  ]
}
```

| Поле | Смысл |
|---|---|
| `id` | **Постоянный уникальный ключ картинки.** Хранить в карточке именно его |
| `title` | Подпись для карточки («Играть в мяч») |
| `category` | Категория (папка) |
| `file` | Путь к файлу относительно базового адреса |
| `bytes` | Размер файла |
| `tags` | Синонимы для поиска (может быть пустым списком) |
| `word` | Слово в нижнем регистре. **Картинки с одинаковым `word` — варианты одной карточки** |
| `variant` | `"девочка"`, `"мальчик"`, `"без людей"` или `""` (не указан) |
| `style` | `"рисунок"` или `"фото"` |
| `n` | Номер варианта: 1, 2, 3… (у слова может быть несколько картинок с девочкой) |
| `w`, `h` | Размер в точках (у SVG этих полей нет) |

**Правила совместимости (важно):**
- Разбирать нестрого: **неизвестные поля игнорировать** — со временем могут добавиться новые.
- Необязательные поля могут отсутствовать: `tags`, `word`, `variant`, `style`, `n`, `w`, `h`.
  Значения по умолчанию: `tags=[]`, `word=title.lowercase()`, `variant=""`, `style="рисунок"`, `n=1`.
- Если `version` > 1 — не падать, показать «обновите приложение» или работать с тем, что понятно.
- Существующие поля не переименовываются и не удаляются — это гарантия со стороны сайта.

## 3. Форматы картинок

- **PNG** (рисунки, с прозрачностью), **WEBP** (фото), **SVG** (изредка) — всё 512 точек по длинной стороне,
  обычно 5–60 КБ.
- WEBP Android показывает сам. **SVG** — нужна поддержка (Coil + `coil-svg`, или AndroidSVG).
  Если SVG поддерживать не хочется — отфильтровать элементы с `file`, оканчивающимся на `.svg`.
- Фон прозрачный: карточку рисовать на своём фоне.

## 4. Русские буквы в адресах

Пути содержат кириллицу: `images/режим/чистить_зубы-девочка.png`.
**Каждый сегмент пути нужно URL-кодировать**, иначе часть библиотек получит 404.

```kotlin
val url = LIBRARY_BASE_URL.toHttpUrl().newBuilder()
    .addPathSegments(item.file)   // OkHttp сам закодирует кириллицу
    .build()
// или вручную: item.file.split("/").joinToString("/") { Uri.encode(it) }
```

## 5. Как приложение должно работать

**Загрузка каталога**
1. При открытии экрана выбора картинки: если кэш каталога старше 24 часов (или его нет) — скачать
   `catalog.json` с заголовком `If-None-Match` (ETag из прошлого ответа). Ответ `304` — кэш актуален.
2. Хранить каталог на устройстве (файл или Room). **Без интернета работать по кэшу.**
3. Нет ни кэша, ни интернета — понятное сообщение «Библиотека недоступна, нужен интернет»
   и возможность выбрать фото из галереи, как раньше.

**Поиск**
- Приводить к нижнему регистру и заменять `ё` на `е` — и запрос, и данные.
- Искать по `title`, `word`, `tags`, `category`. Каждое слово запроса должно найтись хотя бы в одном из полей.
- Сортировка: сначала совпадения по началу `title`, потом по тегам, потом остальное.
- Пример: «пить» находит «Воду» и «Сок» через теги.

**Показ результатов**
- Группировать по `word` (+ `category`): **одно слово — одна плитка**, на ней значок «×3», если вариантов несколько.
- Нажатие на плитку — выбор конкретного варианта (девочка / мальчик / без людей / фото / 2, 3…).
- **Фильтр «Кто на картинке»** — настройка профиля ребёнка (девочка / мальчик / не важно),
  сохранять и применять по умолчанию. Логика: при «девочка» показывать варианты с девочкой;
  если у слова вообще нет вариантов с людьми (магазин, автобус) — показывать их тоже;
  слова, у которых есть только «мальчик», скрывать.
- Превью можно грузить тем же файлом — они маленькие (Coil/Glide с дисковым кэшем).

**Выбор картинки**
- Выбранную картинку **скачать и сохранить в хранилище приложения** (`filesDir/library/<id>.<ext>`),
  в карточке хранить путь к локальному файлу + `id`. Карточка должна работать без интернета навсегда.
- **Не показывать картинки в карточках напрямую по ссылке** (без скачивания) — это ломает офлайн
  и нагружает хостинг.
- Если позже картинку заменят на сайте — у пользователя остаётся старая, это нормально.
  (По желанию: кнопка «обновить картинку» — перекачать по тому же `id`, если `bytes` изменился.)
- Если `id` исчез из каталога — у пользователя картинка остаётся, ничего не делать.

## 6. Что НЕ делать

- Не парсить HTML сайта — только `catalog.json`.
- Не вшивать список картинок в приложение — коллекция растёт каждую неделю.
- Не строить `id` или путь самостоятельно из названия — брать только из каталога.
- Не опрашивать каталог чаще раза в сутки в фоне (при ручном «обновить» — можно).

## 7. Права

Картинки принадлежат автору приложения, использование в «Моём дне» разрешено.
В приложении желательно указать: «Картинки: библиотека „Мой день“ — dikajabelka.github.io/moyden».
Условия для пользователей: https://dikajabelka.github.io/moyden/about.html#rules

## 8. Как проверить

1. Открыть в браузере `https://dikajabelka.github.io/moyden/catalog.json` — должен открыться JSON.
2. Сейчас в библиотеке 14 картинок-заглушек (9 слов). Для теста подходят:
   «чистить зубы», «гулять», «играть в мяч» (у него 3 варианта: девочка, мальчик, мальчик 2),
   «магазин» (без людей), «парк» (фото, WEBP).
3. Проверить поиск «мяч», «зубы», фильтр «девочка», выбор варианта, работу в режиме полёта после выбора.
