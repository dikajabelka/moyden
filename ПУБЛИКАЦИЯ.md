# Как выложить сайт на GitHub

Нужно сделать три вещи на github.com (минут 10). Остальное сделаю я.

## 1. Аккаунт
1. **github.com** → **Sign up** → почта, пароль, имя пользователя → подтвердить почту.
2. **Имя пользователя = часть адреса сайта** (`https://ИМЯ.github.io/kartinki/`).
   Латиница, коротко, потом не менять. Например: `mojden`.

## 2. Пустой репозиторий (хранилище)
1. Справа вверху **+** → **New repository**.
2. Repository name: **`kartinki`**
3. Отметить **Public** (бесплатный сайт работает только с открытыми).
4. Больше ничего не отмечать (без README) → **Create repository**.

## 3. Ключ доступа
Он нужен мне для первой выкладки, а тебе — для входа в админку.

1. Аватар справа вверху → **Settings** → в самом низу слева **Developer settings**.
2. **Personal access tokens** → **Fine-grained tokens** → **Generate new token**.
3. Заполнить:
   - **Token name:** `админка`
   - **Expiration:** самый долгий срок из предложенных
   - **Repository access:** **Only select repositories** → выбрать `kartinki`
   - **Permissions** → **Repository permissions** — поставить **Read and write** у четырёх:
     **Actions**, **Contents**, **Pages**, **Workflows**
4. **Generate token** → скопировать ключ (начинается с `github_pat_…`).
   **Показывается один раз** — сохраните его в заметках.

## 4. Прислать в чат
Имя пользователя и ключ. Я выложу сайт и включу публикацию.

После этого ключ можно в любой момент отозвать (там же — Delete) и сделать новый:
сайт от этого не пострадает, просто в админку нужно будет войти с новым ключом.

---

## Как потом пользоваться
- **Сайт:** `https://ИМЯ.github.io/kartinki/`
- **Админка:** `https://ИМЯ.github.io/kartinki/admin.html` — вход по ключу (один раз на устройство).
- **Каталог для приложения:** `https://ИМЯ.github.io/kartinki/catalog.json`

В админке: перетащить картинки → проверить слово и «девочка / мальчик / без людей» → «Загрузить».
Через 1–2 минуты GitHub сам всё обработает и обновит сайт.

## Важно
- Не переименовывать аккаунт и репозиторий — сменится адрес, приложение потеряет картинки.
- Лучше до выпуска приложения купить свой домен (см. ниже) — тогда адрес не зависит от GitHub.
- Ключ никому, кроме меня в этом чате, не передавать. В админке он хранится только в вашем браузере.

## Свой домен (по желанию)
Адрес вида `kartinki.moj-den.ru` — несколько сотен рублей в год. Подключается в репозитории:
Settings → Pages → Custom domain. Если купите — скажите, помогу настроить.
