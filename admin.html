Вход в админку

Нужен ключ доступа GitHub. Он хранится только в этом браузере. Как его получить — в файле «ПУБЛИКАЦИЯ.md», шаг «Ключ для админки».

Перетащите картинки сюда или нажмите, чтобы выбрать. PNG, JPG, WEBP, SVG — сразу много.

Если файл назван словом из словаря («чистить зубы девочка.png») — всё заполнится само. Иначе впишите слово и выберите, кто на картинке.

Теги — синонимы для поиска через запятую. «Варианты» — какие картинки нужны слову (для плана). Слово, у которого уже есть картинки, переименовать нельзя — сломаются адреса.
